Visual Web Crawler Prototype

Move your mouse around. A small spider lives on the overlay canvas above this page and will chase your cursor, sniff nearby elements, and draw glowing threads to whatever it touches. The page underneath is never modified.

Read the docs →

How it follows you

The spider steers toward your cursor with easing and a little wander wobble, so it feels alive instead of robotic. Stop moving and it will start inspecting whatever is closest.

Learn more

What it detects

Links, headings, paragraphs, buttons, and images within a sniff radius get a glowing outline plus a thread line from the spider. Labels float above them showing the element type.

Overlay rules

Everything visual lives on a single transparent, click-through canvas fixed over the page. No DOM nodes are changed, no layout shifts — just paint on top. Open spider.js to tune speed, sniff radius, and leg wiggle.

Prototype v0.1 — visual crawl only. No multi-page crawl, DB, auth, or AI.
